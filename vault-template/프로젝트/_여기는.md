# 여기는 — 프로젝트

끝나는 날이 있는 일. 폴더 이름은 `과제번호_짧은이름`(예: 101_주문조회)으로 볼트 밖 자료 폴더 이름과 짝을 맞춘다.

새 프로젝트 추가:
1. `000_틀/`을 복사해 폴더를 만들고 `Templates/카드`로 `_카드.md`를 쓴다
2. `현황.md` 표에 한 줄 더한다
3. 끝나면 폴더째 `보관/`으로 옮긴다

작업 저장소 연결(코드 작업 저장소에서 Claude Code를 열 때 이 프로젝트의 지금 · 할 일을 읽게 함):
1. 저장소 경로와 프로젝트를 확인한다. 프로젝트가 하나면 묻지 않는다. 폴더가 있으면 git 저장소가 아니어도 연결한다. 폴더가 없을 때만 만들지 묻는다. clone · `git init`은 사용자가 시킬 때만 한다
2. 그 저장소 `CLAUDE.md`를 직접 열어 아래 두 줄이 있는지 본다(볼트 2절 경로 칸은 연결 여부의 근거가 아니다). 없으면 더하고, 파일이 없으면 만든다
   ```
   @<볼트 경로>/프로젝트/<번호>_<이름>/지금.md
   @<볼트 경로>/프로젝트/<번호>_<이름>/할일.md
   ```
   경로는 그 저장소에서 Claude Code가 보는 경로로 쓴다. Windows는 `@~/Work/…`처럼 `~/`로 시작하고, WSL은 `/mnt/c/…`. 공백은 `\`로 처리하고 따옴표로 감싸지 않는다
3. 볼트 `CLAUDE.md` 2절의 작업 저장소 경로 칸을 채우고 커밋한다(작업 저장소 쪽은 커밋하지 않는다)
4. 사용자에게 알린다: 그 저장소에서 `claude`를 새로 열고, 외부 파일 불러오기 승인 창이 뜨면 허용, `/memory`에 두 파일이 보이는지 확인
