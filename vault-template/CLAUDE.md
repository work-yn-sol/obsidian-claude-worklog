# CLAUDE.md — 업무 볼트

> 라우터다. 어디를 읽을지만 적는다. 절차는 각 폴더 `_여기는.md`에 둔다.
> Claude가 같은 실수를 두 번 하면 3절에 한 줄 더한다. 길어지면 떼어 낸다.

## 첫 실행 (끝나면 이 절을 지운다)

1절에 `{…}` 칸이 남아 있으면, 사용자의 첫 요청을 처리하기 전에 아래를 한 번에 묻는다. 모르거나 "나중에"라고 하면 "미확인"으로 둔다.

1. 소속 · 직급, 맡은 일, 자주 일하는 사람
2. 첫 프로젝트 번호와 짧은 이름(예: 101_주문조회). 없으면 건너뛴다
3. 받은 자료 원본 폴더 경로
4. 코드 작업 저장소에서도 Claude Code를 쓰는지, 쓰면 그 경로
5. Claude가 열지 않을 개인 문서 폴더 경로

답을 받으면:
- 1절 · 2절 · 5절의 `{…}` 칸을 채운다.
- 2번 답이 있으면 `프로젝트/_여기는.md` 절차로 프로젝트를 만든다. `000_틀/`은 남기고, 복사본의 `{번호}` · `{프로젝트 이름}` · `{자료 폴더}` 칸을 채운다.
- 4번 답이 있으면 `프로젝트/_여기는.md` "작업 저장소 연결" 절차를 따른다.
- 이 절을 지우고 git 커밋한 뒤, 사용자의 첫 요청으로 돌아간다.

## 0. 이 볼트

회사 업무 기록. 할 일 · 일지 · 주간 보고 · 과업(WBS) · 회의 · 결정을 둔다. 받은 자료 원본은 볼트 밖 자료 폴더에 두고 여기에는 링크만 둔다.

판단과 결정은 내가 한다. Claude는 기록 초안을 쓰고 근거를 찾는다.

## 1. 나

- **소속** — {소속 · 직급}
- **맡은 일** — {과제와 담당 범위. 출처(WBS 파일 · 확인 날짜)를 붙인다}
- **자주 일하는 사람** — {이름(역할)}

## 2. 경로

| 위치 | 내용 |
|---|---|
| `현황.md` | 진행 중 프로젝트 목록 |
| `일지/` | 하루 한 파일. `To_Process/` → 주간 보고 반영 후 `Processed/` |
| `주간/` | 주 한 파일. 프로젝트별 WBS 입력값 |
| `프로젝트/과제번호_이름/` | 카드 · 지금 · 할일 · 자료 · WBS · 회의 · 결정 |
| `센터/`, `회사/` | 끝없는 부서 업무, 업무분장 · 결재라인 링크 |
| `보관/` | 끝난 프로젝트, 마감이 있던 센터 · 회사 업무(원래 경로째) |
| `Templates/` | 일지 · 주간 · 카드 · 과업 · 회의 · 결정 |
| 볼트 밖 `{자료 폴더 경로}` | 받은 자료 원본 |
| 볼트 밖 `{작업 저장소 경로}` | 코드 작업 저장소. 이 볼트를 `{볼트 경로}`로 본다 |

## 3. 항상 참인 규칙

1. 일지 '메모' 칸과 내가 쓴 문장은 고치지 않는다. Claude는 '한 일' 칸과 Claude가 만든 노트만 쓴다.
2. 수치 · 목록은 실측한다. 문서에 적힌 수치는 낡은 것으로 본다.
3. 문서와 실물(저장소 · 코드 · 자료)이 다르면 실물이 맞다. 임의로 맞추지 말고 차이를 보고한다.
4. 기록에는 출처를 붙인다(리비전 · 파일 경로 · 회의 날짜). 출처가 없으면 "출처 미확인"이라고 적는다.
5. 되돌리기 어려운 변경은 나눠서 단계마다 확인받는다. Claude가 쓴 변경은 작업 단위로 git 커밋한다.
6. 결정은 내가 한다. Claude는 제안까지만 한다.
7. 한국어, 짧은 평서문과 표로 쓴다. 과장 · 강조 기호 남발을 피한다.

## 4. 작업별 먼저 읽을 것

| 요청 | 읽을 것 · 하는 일 |
|---|---|
| "오늘 할 일 없어?" | `현황.md`의 진행 중 프로젝트마다 `지금.md` · `할일.md`를 읽고 마감 지난 것 → 오늘 마감 → 나머지 순으로 제안 |
| "일지 써줘" | `일지/_여기는.md` 절차대로. 한 일 · 다음 근무일 할 일 · `지금.md`까지 |
| "주간 보고 써줘" | `주간/_여기는.md` |
| "회의 기록해줘" · "결정 기록해줘" | 프로젝트 `_여기는.md`, `Templates/회의` · `Templates/결정` |
| "지금 갱신" | 프로젝트 `지금.md`를 덮어쓴다. 20줄 안팎, 하는 중 · 미결만. 할 일은 `할일.md` 한 곳에만 쓴다 |
| 새 프로젝트 | `프로젝트/_여기는.md` |
| "작업 저장소 연결해줘" | `프로젝트/_여기는.md` "작업 저장소 연결" |
| 자료 찾기 | 프로젝트 `자료.md` → 없으면 볼트 밖 자료 폴더 원본 |

## 5. 하지 않는 것

- 개인 문서 폴더(`{경로}`)는 열지도, 목록을 보지도 않는다.
- 파일 이름에 `대외비` · `비밀값`이 있으면 읽지 않는다.
- 자료 원본을 볼트로 복사하거나 원본 폴더를 고치지 않는다.
- 상주 자동화 · 훅 · 스킬을 만들지 않는다. 같은 요청이 세 번째일 때 검토하고, 내가 시킬 때만 만든다.
