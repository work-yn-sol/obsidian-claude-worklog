# 여기는 — 주간 보고

주 한 파일. 이름은 `YYYY-Www.md`(예: 2026-W46), 양식은 `Templates/주간`. 금요일에 그 주 `일지/To_Process/`를 묶어 문서를 쓰고, 다음 주 주간 보고에서 공유한다. 프로젝트별 WBS 칸은 금요일 WBS 입력값과 같다.

맨 위 '주요 업무 공유' 절은 보고 자리에서 읽을 문장이다. '이번 주'에는 '한 일(상세)' 중 주요 업무 O인 줄을, '다음 주'에는 '다음 주' 절의 줄을 보고용 문장으로 한 줄씩 다시 쓴다. 무엇을 했고 어디까지 됐는지(다음 주는 무엇을 할지)를 명사형으로 끝낸다(예: `주문 검색 API 조건 2개 구현(a1b2c3d), 테스트 통과` → `주문 검색 기능 1차 개발 완료`). 리비전 · 파일 경로 · 사람 이름 · 과업 번호는 빼고, 근거는 '한 일(상세)' 표에 둔다.

'피드백' · '추가 전달 사항'은 주간 보고 자리에서 받은 피드백 · 추가로 전달받은 것을 내가 적는 칸이다. Claude는 고치지 않는다.

보고를 쓴 뒤 각 프로젝트 `할일.md`의 `[x]` 항목을 지운다. 기록은 주간 보고와 git 이력에 남는다.
